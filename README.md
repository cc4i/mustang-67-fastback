# 1967 Ford Mustang Fastback - 1:24 printable model

![The real car (left) and the model (right), front 3/4 from the driver's side](docs/images/front34_driver.jpg)

A 1:24 scale, multi-colour 3D-printable model of a burgundy 1967 Ford Mustang Fastback. It is built procedurally in Blender from the Python modules in `mustang/`. Nothing is sculpted by hand: the body shell, the opening hood and doors, the engine bay, the interior, the wheels and all the trim are generated by code. The model is matched against the dealer photos in [`origin_images/`](origin_images/).

The build produces print-ready STLs, a Bambu Studio project, STEP solids for CAD tools such as Shapr3D, a showcase animation and a Blender scene.

## What is modelled

- **Body:** lofted from station cross-sections, using real-car dimensions scaled to 1:24. It includes the fastback roof, side scoops, C-pillar louvers, twin hood scoops, cowl louvers, window recesses, a set-back tail panel, fender badges, drip rails and chrome trim. The windshield and rear glass are black inlays printed as part of the body.
- **Opening hood:** pivots on two printed pegs that drop into slots in the body. A prop rod holds it open.
- **Opening doors:** each door swings on a piece of 1.75 mm filament glued into the sill. Each door carries a black door card, a chrome vent window and, on the driver's side only (as on the real car), the mirror.
- **Engine bay:** a black liner holds the inner fenders, shock towers, firewall, radiator, battery, washer bottle and brake booster. A blue small-block V8 sits in it, with black Cobra valve covers and air cleaner and a V brace.
- **Interior:** a black tub (floor, seats, console and dashboard) slides up into the cabin from below. The steering wheel plugs into the dash.
- **Rolling chassis:**
  - five-spoke chrome rims and tires
  - octagonal axles that press into the rims and spin in the chassis bosses
  - the chassis plate, differential cover and exhaust tips
- **Lights and trim:**
  - the grille with its corral and running horse (traced from photo (4))
  - fog lamps, headlights and parking lamps
  - three-element taillights (red lenses in chrome bezels) and backup lamps
  - the gas cap
  - wrap-around blade bumpers with guards

The assembled model measures about 188 x 76 x 55 mm.

## Printing

`mustang/make_project.sh` generates a Bambu Studio project with these settings:

- **Printer and profile:** Bambu Lab X2D, 0.4 mm nozzle, the "0.12mm High Quality" profile, Bambu PLA Basic. Walls use the Arachne generator so fine details survive.
- **Parts:** 40 STL files making 60 pieces, in five colours:
  - burgundy `#6B0F1A`: body, hood, doors
  - black `#1A1A1A`
  - silver `#C8C8CC`: the chrome parts
  - red `#B01010`: taillight lenses
  - blue `#2B59C3`: engine block
- **Plates:** 8, one or more per colour group. The body, hood, doors and rear bumper each get a plate of their own.
- **Supports:** tree supports on the body, hood, engine block and rear bumper only.
- **Last slice (9 Oct 2026):** about 16 hours and 185 g of PLA in total. The body plate alone takes about 8 hours.

How the parts go together:

1. Slide the interior tub into the cabin. Then glue on the chassis plate (its axle bosses key into slots in the body floor), the differential cover beneath it, and the exhaust tips into their floor slots.
2. Push the axles through the chassis bosses into the rims, then press the tires over the rims.
3. Glue a short length of 1.75 mm filament into each sill pin hole and slide the doors down onto the pins. The door cards glue to the doors' flat inner faces. The mirror's peg goes into the slot in the driver's door top.
4. Drop the hood's pivot pegs into their slots. The brace goes in last.

## Building from source

Requirements:
- Blender 5.1 or newer
- Bambu Studio, for the project and slicing
- ffmpeg, for the animation and the comparison sheets
- python3
- [uv](https://docs.astral.sh/uv/), for the STEP export

**1. Build, check and export in Blender.** Use the Python console, or a script run with `Blender -b --python`:

```python
import sys; sys.path.insert(0, "/path/to/1967mustang-project/mustang")
import build, printcheck, export
build.main()            # rebuilds every part (several minutes)
printcheck.run()        # manifold, overlap and mirror checks: every list should be empty
export.run()            # output/stl/*.stl + manifest.json, in print orientation
export.run_assembled()  # output/stl_assembled/: parts in place, plus their names and colours
```

**2. Build the Bambu project:** `mustang/make_project.sh [OUT.3mf]`. The default output is `output/mustang_67_fastback_1-24.3mf`. The project is generated from scratch, so this replaces any changes saved into that file from Bambu Studio. Pass a different path to keep them.

**3. Make the CAD files:** `uv run mustang/make_step.py` turns `output/stl_assembled/` into STEP solids that Shapr3D and other CAD tools can measure, snap to and edit (Shapr3D imports an STL only as a reference mesh). It writes one file per part into `output/step/`, each in its place on the car, and the whole car as one assembly of named, coloured parts, `output/mustang_67_fastback.step`. Every triangle becomes a flat face, so the files keep the full detail and are large: about 670 MB for the whole car, 230 MB of it the body. The run takes about 5 minutes and fails unless every part comes out a valid closed solid.

**4. Make renders and the animation.**
- `studio.render("Cam_P1", "tmp/renders/p1.png")` renders a view.
- `animate.setup()` bakes and keys the showcase animation. Save the scene, then render it headless from the project root:

  ```sh
  Blender -b output/mustang_67_fastback.blend --python-expr "import sys; sys.path[:0] = ['mustang']; import animate; animate.render()"
  ffmpeg -framerate 24 -i tmp/anim_frames/frame_%04d.png -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart output/mustang_hood_doors_animation.mp4
  ```

- `mustang/readme_images.sh` rebuilds the photo-vs-model pairs in `docs/images/` from the animation frames.

## Layout

| Path | Contents |
|---|---|
| `mustang/` | Source: `build.py` (entry point), geometry modules (`body`, `features`, `details`, `bumpers`, `doors`, `engine_bay`, `interior`, `wheels`), `materials`, `printcheck`, `export`, `studio`, `animate`, the Bambu tooling (`make_project.sh`, `merge_3mf.py`, `bambu_presets.py`, `check_plates.py`, `inspect_3mf.py`), the STEP export (`make_step.py`), `readme_images.sh` |
| `origin_images/` | Reference photos |
| `docs/images/` | The README's photo-vs-model pairs (generated, but tracked so GitHub shows them) |
| `output/` | Deliverables: `mustang_67_fastback.blend` (the scene, including the photo-matched cameras), `mustang_67_fastback_1-24.3mf`, `mustang_hood_doors_animation.mp4`, `stl/`, `stl_assembled/`, `step/`, `mustang_67_fastback.step` |
| `tmp/` | Scratch: renders, comparison sheets, animation frames, old project copies. Safe to delete |

Generated files go to `output/` or `tmp/` (see `mustang/paths.py`), apart from the README images in `docs/images/`; nothing is written to the project root. For the code's internals, see [`AGENTS.md`](AGENTS.md).
